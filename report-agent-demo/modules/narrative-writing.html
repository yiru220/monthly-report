基于大模型将数据洞察转化为专业、流畅的分析文案，支持多种语气与行业风格。

Capabilities

核心能力

🤖

数据到文案

把统计结果直接交给大模型，生成「数据总览 / 趋势分析 / 维度分析 / 结论与建议」四段式专业正文。

🎛️

风格可控

语气（严谨 / 汇报 / 轻快）与行业风格可配置，同一份数据可以产出多种表达版本。

🔒

只基于真实数字

Prompt 明确约束只基于给定统计结果分析与推断，不编造任何数据或结论。

🛡️

双重兜底

AI 调用失败时自动回退到内置规则模板，报告生成永不中断。
